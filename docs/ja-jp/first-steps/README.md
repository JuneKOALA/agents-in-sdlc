「はじめの一歩」のワークショップは、既存のアプリケーションや詳細な開発シナリオがなくても GitHub Copilot を体験できる、ガイド付きの入門コースです。どのワークショップも小さなところから始め、製品を使いながら機能を学び、ワークフロー全体を体験します。

すべてのワークショップで、空のフォルダーから同じ Space Quiz を構築します。学びたいツールを選ぶことも、複数のワークショップを完了してそれぞれの使い方を比較することもできます。

> [!NOTE]
> これらのワークショップは [James Montemagno][james] が作成した [First Steps with GitHub Copilot][source-lab] を基に構成し、[MIT License][source-license] の下で公開しています。

## ワークショップ

### [GitHub Copilot app を体験する][copilot-app]

空のフォルダーからカラフルな Space Quiz を構築し、開発の流れを体験します。作成、改善、テスト、プロジェクト指示の記録、公開、作業の計画、Issue の実装、プルリクエストのレビューとマージ、定期作業の自動化を行い、Canvas 拡張機能も試します。

### [GitHub Copilot CLI のはじめの一歩][copilot-cli]

ターミナル中心の開発の流れを学びます。Git に変更を書き込む前に構築と差分のレビューを行い、worktree でセッションを並行実行し、編集前に計画を立ててコンテキストを管理します。その後、シェルを離れずにプルリクエストを作成、マージし、作業を委任します。

### [Visual Studio Code のはじめの一歩][vscode]

エディター中心の開発の流れを体験します。ワークスペースで構築し、統合ブラウザーで UI を整え、コンテキストを確認して、Git に変更を書き込む前にテストします。編集前に計画を立て、VS Code を離れずに GitHub のツールで Issue、プルリクエスト、クラウドセッションを扱います。
